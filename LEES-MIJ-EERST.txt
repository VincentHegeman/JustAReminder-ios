JustAReminder — Family mobiele formulierfix — 1 november 2026

OPLOSSING
De algemene CSS van Slim invoeren behandelde vinkjes als gewone tekstvelden.
Ook de gewone Family-wizard voor taken/herinneringen en ontvangers is
responsief gemaakt: compacte vinkjes, naam naast de keuze, één kolom op iPhone.
De privéwizard heeft geen Family-ledenkeuze en is ongewijzigd.

ZO UPLOAD JE HET NAAR GITHUB (GEEN COMPUTER OF TERMINAL NODIG)
1. Pak dit ZIP-bestand uit.
2. Open https://github.com/VincentHegeman/JustAReminder-ios
3. Upload in de HOOFDMAP deze drie bestanden:
   - fix-family-mobile-forms.mjs
   - test-family-mobile-forms.mjs
   - codemagic.yaml  (de bestaande vervangen)
4. Commit changes.
5. Start in Codemagic workflow ios-ipa-controle op branch main.
6. Installeer de NIEUWSTE build via TestFlight op een fysieke iPhone.
7. Test 'Slim invoeren' én het normale Family-formulier met minstens
   twee gezinsleden, zowel voor Taak als Herinnering.

Deze Codemagic workflow past de Family HTML aan tijdens de iOS-build.
De WEBSITE verandert niet automatisch; om dezelfde fix op de website te
publiceren moet de installer eenmalig op de echte repository worden uitgevoerd
met: node fix-family-mobile-forms.mjs .
Commit daarna de gewijzigde www/family/family-dashboard.html in de website-repository.

GEEN live betalingen ingeschakeld; geen gegevens gewijzigd; geen App Store-release.
